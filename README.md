# LANVC — Виртуальная локальная сеть для игр и совместной работы

LANVC (LAN Virtual Controller) — современный программный комплекс для создания защищённых виртуальных локальных сетей (VLAN) между компьютерами под управлением Windows 10/11 через собственный центральный сервер.

Является функциональным аналогом Radmin VPN, созданным с акцентом на высокую скорость, низкую задержку в играх, устойчивость к сетевым блокировкам и бескомпромиссную безопасность.

## Ключевые возможности

- 🎮 **Полноценная поддержка LAN-игр:**
  - Поддержка TCP и UDP трафика между всеми участниками сети.
  - Специальный модуль широковещательной (Broadcast) и многоадресной (Multicast) маршрутизации для автоматического обнаружения серверов в играх (Minecraft LAN, Counter-Strike/Source Engine, Terraria, Unreal Engine, Warcraft III, DirectPlay и др.).
- 🚀 **Модульный транспорт высокой доступности:**
  - **Основной: QUIC (UDP) с TLS 1.3** и ненадежными датаграммами (RFC 9221) — отсутствие Head-of-Line Blocking, ультранизкий пинг в играх.
  - **Резервный: WebSocket (TCP) через порт 443 HTTPS** с TLS 1.3 — преодоление корпоративных файрволов и провайдерских DPI, блокирующих UDP.
  - Автоматическое плавное переключение между транспортами.
- ⚡ **Виртуальный сетевой адаптер Wintun:**
  - Официальный WHQL-подписанный драйвер ядра от WireGuard.
  - Установка без перезагрузок и отключения цифровых подписей.
  - Высочайшая пропускная способность при нулевой нагрузке на процессор.
  - Безопасное назначение виртуальных IP (по умолчанию `10.77.0.X/24`) без нарушения работы обычного интернета.
- 🔒 **Безопасность корпоративного уровня:**
  - Все соединения зашифрованы по стандарту TLS 1.3.
  - Защита от MITM через проверку SHA-256 отпечатков сертификатов.
  - Хранение паролей на сервере в виде хешей **Argon2id** с криптографической солью.
  - Хранение паролей на клиенте в защищенном хранилище **Windows Credential Manager**.
  - Защита от брутфорса (Token Bucket Rate Limiting) и атак с подменой IP (Anti-Spoofing).
- 🎨 **Современный темный интерфейс (WPF):**
  - Минималистичный дизайн в стиле Discord / Telegram.
  - Список участников сети в реальном времени с отображением задержки (ping), статуса и времени онлайн.
  - Мониторинг скорости, счетчики пакетов и график активности.
  - Сохранение профилей серверов и автоматическое переподключение.
- 🖥️ **Сервер для Windows 11 Pro:**
  - Работа в качестве Windows Service с автозапуском.
  - Обслуживание до 10 одновременных участников на процессорах Intel Core i3-12100F с минимальным расходом ОЗУ.
  - Утилита администрирования `LANVC.Admin` для быстрой смены настроек, пароля и кика участников.

## Быстрый старт

### Шаг 1. Запуск сервера (на компьютере со статическим белым IP)

1. Откройте PowerShell от имени Администратора в папке сервера.
2. Задайте пароль сети:
   ```powershell
   .\LANVC.Admin.exe set-password "ВашНадежныйПароль"
   ```
3. Зарегистрируйте и запустите службу Windows:
   ```powershell
   .\install-service.ps1
   ```
   *Служба `LANVC.Server` будет запускаться автоматически вместе с Windows.*

### Шаг 2. Подключение клиентов

1. Запустите `LANVC.Client.exe` на клиентском компьютере (Windows 10/11).
2. Введите **IP-адрес сервера** (например, `203.0.113.42`), порт `443` и пароль.
3. Нажмите кнопку **«▶ Подключиться»**.
4. Клиент получит свой виртуальный IP (например, `10.77.0.2`), а в списке участников справа появятся остальные игроки!
5. Запустите любимую игру и создайте локальный сервер (LAN) — остальные участники увидят его автоматически!
