# LANVC — Журнал изменений (CHANGELOG.md)

## [1.0.0] - 2026-11-18

### Добавлено
- **Архитектура Hub-and-Spoke:** централизованная виртуальная локальная сеть с сервером-диспетчером, обслуживающим до 10 одновременных участников.
- **Модульная транспортная подсистема:**
  - Основной транспорт: QUIC (RFC 9000, RFC 9221) с TLS 1.3 и поддержкой ненадёжных датаграмм для минимальной задержки в играх.
  - Резервный транспорт: WebSocket поверх TLS 1.3 на стандартном HTTPS порту 443 с корректным HTTP/1.1 Upgrade.
  - Автоматическое обнаружение блокировок UDP/QUIC и бесшовное переключение на резервный WebSocket.
  - Ручной выбор транспорта пользователем.
- **Драйвер виртуального адаптера Wintun:**
  - Официальный WHQL-подписанный драйвер `wintun.dll`.
  - Автоматическое создание адаптера, динамическое назначение IP (`10.77.0.X/24`) и безопасное удаление при отключении.
  - Отсутствие влияния на основное интернет-подключение (default gateway не перезаписывается).
- **Поддержка LAN-игр (Broadcast & Multicast):**
  - Поддержка широковещательных пакетов (`255.255.255.255`, `10.77.0.255`).
  - Поддержка многоадресных пакетов (`224.0.0.0/4`).
  - Встроенный игровой Discovery Relay для Minecraft LAN (порт 4445), Source Engine (27015/27016), DirectPlay, Terraria, Warcraft III.
- **Безопасность:**
  - Шифрование TLS 1.3 для всех коммуникаций.
  - Хранение паролей на сервере в виде криптографических хешей Argon2id с солью.
  - Хранение паролей на клиенте в Windows Credential Manager.
  - Защита от подбора паролей (Token Bucket Rate Limiting).
  - Защита от спуфинга IP-адресов внутри виртуальной сети.
- **Графический интерфейс клиента (WPF, .NET 10):**
  - Современная темная тема в стиле Discord / Telegram в точном соответствии с макетом.
  - Быстрое подключение по IP и паролю.
  - Отображение статуса, времени сессии, назначенного виртуального IP с кнопкой копирования.
  - Индикатор транспорта (QUIC / WebSocket) и качества сигнала.
  - Монитор сетевой статистики в реальном времени (МБ/с, пакеты, пинг, график).
  - Интерактивный список участников сети с отображением пинга, времени и статуса.
  - Менеджер профилей подключений.
  - Диагностический раздел с экспортом отчёта.
- **Серверная часть:**
  - Поддержка работы в качестве Windows Service.
  - Административная консоль `LANVC.Admin` для смены паролей, управления клиентами и просмотра статистики.
  - Скрипты автоматической инсталляции и настройки Windows Firewall.
